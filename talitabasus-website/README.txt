Website files for talitabasus.github.io

Upload these items to the ROOT of your GitHub repository:
- index.html
- logo.png
- photos/ (including photo-01.jpg)

The supplied screenshot's hero photograph and logo have been cropped into
separate assets so the page reproduces the reference layout. Replace/add
photos in the photos folder. To add more photos, edit the `photos` array in
index.html and list each filename in display order, for example:
  "photos/photo-01.jpg",
  "photos/photo-02.jpg",
  "photos/photo-03.jpg"

The hero image area advances to the next image on click once there are at
least two image paths in the array. The footer uses Outfit from Google Fonts.
